# Issue Tracker

Открытые задачи этого репозитория ведутся в корневом `todos.md`; завершённые — в `todos-completed.md`. Внешние GitHub/GitLab Issues не создаются.

- Новая задача — новый раздел `## [ ] <номер>. <название>`.
- Завершённую задачу перенести в `todos-completed.md` с заголовком `## [x] ...`.
- Детали, критерии готовности и порядок задач живут рядом с задачей.
- При triage писать canonical label отдельной строкой в разделе задачи: `- Triage: \`<label>\``.
